# v0.372 - Single-Frame RTS Visual Recovery

READY FOR HUMAN V0372 RTS VISUAL COMPOSITION REVIEW

This six-file upload pack is a world-only, opt-in composition gate. The primary
frame is intentionally free of HUD, labels, selection rings, debug text, and
evidence annotations so the human reviewer can judge settlement, resource,
river, bridge, roads, and hostile camp as one composition.

Launch the isolated scene with:

`npm run godot:play:quaternius-visual-recovery`

Regenerate the four rendered frames with:

`npm run godot:capture:quaternius-visual-recovery`

The retained v0.370 proof scene, v0.371 playable scene, true default runtime,
and accepted gameplay semantics are not modified by this visual-only route.
This pack is submitted for human review and does not claim acceptance.
