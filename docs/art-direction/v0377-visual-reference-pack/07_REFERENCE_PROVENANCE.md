# Reference Provenance

The four PNGs in this directory were generated specifically for the Ascendant
Realms v0.377 art-direction workflow using OpenAI image generation on
2026-07-24.

They are original concept references for this project. They are not extracted
from a commercial game, purchased asset pack or third-party production source.

They may be used as visual guidance for original models, materials, scenes and
internal development documentation. They are not runtime textures and should
not be shipped as in-world art without a separate explicit decision.
