# Economy direction

Resources should create legible choices: gather, build, train, research, prepare, or save for pressure. Costs and income must be visible, deterministic, and connected to the action the player just took.

The current prototype already contains campaign and battle resources, sites, rewards, upgrades, and compact modifiers. Treat current numeric values as implementation facts from data and simulation, not as a license to retune. Balance work requires telemetry plus player evidence and must remain separate from UI or art changes.
