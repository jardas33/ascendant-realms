# Native-input smoke tests

Use a clean, normal player path: launch, choose the intended match, select an entity, issue a command, inspect feedback, open the relevant action card, and return through the expected result flow. Avoid test-only shortcuts when validating player usability.

For each smoke test record resolution, window/fullscreen mode, input device, exact clicks/keys, observed state, and evidence path. If the machine cannot expose a headed window, classify the run as an environment limitation rather than a gameplay pass.
