## Documentary basis

The user supplied the Tesana Terms screenshot and confirmed an active Pro paid subscription. The current official Tesana documentation was checked on 2026-07-29:

- Terms: https://tesana.ai/en/terms
- Exports: https://docs.tesana.ai/building/exports
- FAQ: https://docs.tesana.ai/support/faq
- Remixing: https://docs.tesana.ai/building/remixing

The Exports page states that paid plans unlock the complete Godot source export, including GDScript, scenes and raw assets, and that paid-plan exports can be sold and distributed. The FAQ states that paid-plan creators own their games with commercial rights that survive cancellation. Remixing is a separate case; this project is recorded as the user's original game, not a third-party remix.

The supplied export contains the complete source project and was copied into the production candidate without generated `.godot` cache files. Non-exclusive generated assets are admitted as part of the user's exported game under this rights basis. An individual file will be separately flagged only if it contains explicit contradictory third-party licensing metadata.
