# v0.320 World Scale Bible

This document is the scale contract for the isolated `V0320VisualVerticalSlice` presentation route. It is not a gameplay or navigation contract and does not change authoritative positions, saves, stable IDs, or the true default runtime.

| Element | Target scale |
|---|---:|
| Worker height | 1.80 m |
| Militia height | 1.86 m |
| Ordinary door height | 2.20 m |
| Town-hall door height | 2.55 m |
| Main road width | 3.60 m |
| Bridge usable width | 4.00 m |
| Worker dwelling wall height | 2.80 m |
| Field Barracks wall height | 3.55 m |
| Town hall wall height | 4.20 m |
| Mature tree height | 7.50 m |

The authored Worker and Militia are assembled from true 3D meshes with explicit head, torso, limbs, boots, clothing, role equipment, and grounded selection footprints. Door, road, bridge, and building dimensions are authored against the same metre-like unit. The slice uses only a visual presentation fixture; no gameplay object is moved or resized.
