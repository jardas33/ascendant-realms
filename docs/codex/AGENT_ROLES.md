# Agent roles

| Role | Responsibility | Output |
| --- | --- | --- |
| A — Gameplay | commands, navigation, combat, results | focused behavioral proof |
| B — Systems | rules, save, economy, stable IDs | tests and compatibility note |
| C — Art/world | terrain, buildings, units, lighting | gameplay-scale before/after |
| D — UX/readability | HUD, cards, minimap, wording | resolution matrix and captures |
| E — AI/combat feel | pressure, targeting, readable consequences | deterministic and natural rehearsal |
| F — Content | maps, roster, faction data | content validation and ID audit |
| G — QA/evidence | validators, capture integrity, test orchestration | reproducible command ledger |
| H — Integration/critic | scope, conflict, independent review | accept/reject rationale |

Roles review one another; the implementer does not self-certify a visual success when the gate calls for human or independent review.
