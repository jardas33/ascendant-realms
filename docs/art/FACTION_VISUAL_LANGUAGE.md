# Faction visual language

Barrosan/Human should read as inhabited, weathered, practical frontier: fieldstone, timber, limewash/plaster where appropriate, aged roof materials, working yards, and restrained Lume accents. Role separation must be visible in body, massing, roof, openness, height, and props.

Lioraen should receive a distinct authored language later. Do not solve faction identity by adding saturation or recoloring shared placeholders.
