## Executive decision

**ADOPT H3 DIRECTIONAL ANIMATION PIPELINE FOR WORKER AND MILITIA**.

This is a bounded, opt-in presentation pilot. It does not approve the animated assets as final player-facing art and does not enable them in the default runtime.

## Worker animation contract

Worker binds authoritative `activityState=working` to work, travelling/move-ordered to locomotion, and all other supported stopped/idle states to idle. The atlas contains 4 idle frames, 6 locomotion frames, and 6 work frames per authored family. Work begins only after the real working state is present.

## Militia animation contract

Militia binds idle and travelling/move-ordered only. The atlas contains 4 idle and 6 locomotion frames per authored family. No Militia ready state or ready animation was invented.

## Directional strategy

The runtime exposes north, north-east, east, south-east, south, south-west, west, and north-west. Four authored families are present: south, east, north, and west. Compatible diagonal outputs use explicit mirror classification. Each proxy records facing, frame index, frame phase, source lineage, and the M3 method in metadata.

## Atlas and frame architecture

Worker and Militia each use one transparent 128-pixel cell atlas. Worker has 64 physical cells (4 families × 16 state frames); Militia has 40 physical cells (4 × 10). The full review pack records 104 physical cells, 80 exact unique cells, and 21 perceptual identities; state-family exact uniqueness is audited and locomotion/work cycles contain the required distinct frame counts.

## Runtime state binding and synchronization

Animation updates only the billboard material and phase metadata. Proxy roots are placed from authoritative `runtime.units.position` during sync. Root motion is false. Selection rings and contact shadows remain children of the same proxy root. Direction is read from authoritative `runtime.units.facing`; locomotion stops when authoritative arrival clears travelling state.

## Worker work-state result

The real `assign_worker_to_mine` state was exercised. The work cycle is bound to `activityState=working`; it is not shown for idle or travelling Worker captures.
