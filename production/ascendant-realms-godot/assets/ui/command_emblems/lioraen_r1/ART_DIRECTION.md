# Lioraen command emblems, local visual candidate

These two generated raster illustrations give the Lioraen command deck its own woodland visual identity. The square `field_orders_atlas.png` has four equal quarters: Attack Move (leaf blade), Stop (open hand), Hold (rooted shield), and Patrol (linked waystones). `rallying_cry.png` shows a Grove Warden sounding a living-wood horn. Their jade, ivory, and deep evergreen palette is distinct from the red-banner Barrosan set while retaining high-contrast silhouettes at the 44 px card size.

The atlas is consumed by the existing order-quadrant map. Action IDs, hotkeys, command callbacks, cooldowns, save data, and race definitions are unchanged. Original generated files remain in the Codex generated-images directory; these copies are the authored candidate assets for this lane.
