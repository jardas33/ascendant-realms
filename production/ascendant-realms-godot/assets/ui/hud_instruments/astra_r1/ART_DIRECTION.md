# Top metric bezel, local visual candidate

`metric_bezel.png` is a blank forged-bronze instrument frame for the live resource and force values. It has a quiet dark center for two rows of UI text, thin antique-gold filigree, and side bosses that connect visually when the metric tiles sit close together. The same frame is reused across economy and army readings; each metric retains its live accent, label, icon, value, tooltip, and accessible control.

The art follows the user's aspirational HUD reference while keeping the battlefield visible between the top groups. The original generated image remains in Codex generated images; this copy is the authored asset for the isolated UI candidate.

The joined selection/command chassis also samples only the bezel's narrow top and bottom metal bands for its exposed rails. Its live contents remain on the existing dark reading surface and keep their responsive layout and input behavior.

`resource_objects_atlas_r1.png` supplies transparent, painterly objects for the four economy readings: apple, cut logs, quarried stone, and gold coins in reading order. The HUD samples each quadrant through an `AtlasTexture` with transparent gutters cropped in the region; the original resource icon files remain available to other screens. Numeric values and resource identifiers remain live and unchanged.
