# Lioraen construction illustrations, R1

These transparent illustrations appear only in compact worker build cards. The
world models and selected-building live 3D portraits remain unchanged.

The shared generation brief was a single complete structure, centered in an
elevated three-quarter isometric view with transparent breathing room. The
Lioraen visual language uses pale ivory living wood, deep weathered bark,
restrained moss and leaves, organic arches, jade/teal magic, and small amber
lights. Materials should feel tactile, with a strong silhouette that reads at
68 px. No terrain base, scenery, people, text, UI frame, logos, or watermark.
